# MOZI 캐릭터 조합 프로토타입

## 목적과 범위

이 문서는 원본 캐릭터 12종을 기준으로 새 픽셀 몬스터를 조합하기 위한 승인용 설계다. 현재 서비스의 전체 캐릭터 생성 엔진에는 연결하지 않는다. `/prototype/characters` 화면의 5종을 확인하고 디자인 승인을 받은 뒤에만 감정 16종·세부 상태 20종 전체로 확장한다.

## 원본 12종에서 확인한 공통 규칙

- 투명 이미지 크기는 대략 140~160px이고, 프로토타입 공통 캔버스는 `160 × 160px`이다.
- 몸통은 화면 폭의 약 80~90%를 차지하는 낮고 둥근 젤리형이다.
- 바닥 기준선은 `y=145`로 통일한다.
- 외곽선은 검정에 가까운 남보라색 `#11112F`, 안쪽 방향 약 4px로 사용한다.
- 얼굴은 `x=48~112`, `y=69~122` 안에 배치한다.
- 눈썹 기준선은 `y=69~78`, 눈 중심은 `y=86~94`, 입은 `y=108~121`이다.
- 몸통은 단색 하나를 중심으로 하고 그라데이션, 그림자와 안티앨리어싱을 만들지 않는다.
- 장식은 최대 1개, 효과는 최대 2개만 사용한다.
- 장식은 `top`, `top_sides`, `right_hand` 앵커에만 배치한다.
- 얼굴 의미가 충돌하면 주요 감정은 눈썹·입, 보조 감정은 눈에 우선 반영한다.

## 재사용 에셋 구조

```text
frontend/public/assets/character-prototype/
├─ bodies/
│  ├─ wide.png
│  ├─ soft.png
│  ├─ low.png
│  └─ tall.png
├─ parts/
│  ├─ eyebrows/
│  ├─ eyes/
│  ├─ mouths/
│  ├─ decorations/
│  ├─ effects/
│  └─ mutations/
├─ examples/
│  └─ 승인용 캐릭터 5종
└─ prototypes.json
```

몸통 실루엣은 원본 캐릭터의 가장 큰 연결 영역에서 가져온다. 얼굴과 색상은 제거하고, 실루엣과 4px 외곽선만 템플릿으로 보존한다. 눈썹·눈·입은 모두 같은 `160 × 160px` 투명 레이어라서 별도의 위치 보정 없이 겹칠 수 있다.

## 레이어 순서와 좌표 규칙

| 순서 | 레이어 | 규칙 |
| --- | --- | --- |
| 1 | 몸통 | 중앙 정렬, 바닥 `y=145` |
| 2 | 장식 | 지정 앵커 하나만 사용 |
| 3 | 돌연변이 | 몸통 면적의 5% 미만 |
| 4 | 눈썹 | `x=48~112`, `y=69~78` |
| 5 | 눈 | `x=49~111`, `y=82~108` |
| 6 | 입 | `x=61~99`, `y=108~121` |
| 7 | 효과 | 얼굴을 가리지 않는 바깥 영역 |

호환되지 않는 조합은 생성 후보에서 제외한다. 예를 들어 왕관과 비구름처럼 같은 `top` 앵커를 차지하는 장식 두 개는 함께 사용할 수 없다. 눈물 눈과 소용돌이 눈처럼 같은 눈 슬롯을 사용하는 파츠도 동시에 선택할 수 없다.

## 감정 조합 규칙

1. 주요 감정이 몸통 색상, 눈썹과 입을 고른다.
2. 첫 번째 보조 감정이 눈 파츠를 바꾼다.
3. 세부 상태가 장식 또는 작은 효과 하나를 추가한다.
4. 강도 0~100은 5단계로 나누고, 단계가 높을수록 표정의 기울기와 효과 사용 가능성이 커진다.
5. 몸통 템플릿과 허용된 장식 후보는 저장된 랜덤 시드로 선택한다.
6. 같은 분석 결과라도 다른 시드를 발급하면 다른 허용 조합이 가능하지만, 결과가 확정된 뒤에는 시드를 저장해 같은 외형을 재현한다.

## JSON 계약

정식 스키마는 [character-generation.schema.json](./schemas/character-generation.schema.json)에 정의한다. 프로토타입의 실제 데이터는 `frontend/public/assets/character-prototype/prototypes.json`에 저장한다.

핵심 필드는 몸통, 표정 3개 슬롯, 감정 강도, 장식, 효과, 돌연변이와 재현용 시드다. 허용 목록 밖의 파츠 ID와 색상은 거부한다.

## 승인용 조합 5종

| 캐릭터 | 감정 조합 | 핵심 표현 |
| --- | --- | --- |
| 부글꾸벅 | 분노 70 + 피로 30 | 화난 눈썹, 반눈, 삐뚤어진 입, 커피 |
| 콩닥초조 | 설렘 65 + 불안 35 | 반짝이는 눈, 걱정 눈썹, 식은땀, 하트 |
| 비구름몽 | 슬픔 60 + 외로움 40 | 처진 눈썹, 눈물, 비구름 |
| 으쓱졸림 | 뿌듯함 70 + 피로 30 | 자신감 눈썹, 반눈, 왕관 |
| 갸웃멍 | 혼란 55 + 무기력 45 | 비대칭 눈썹, 서로 다른 눈, 물음표 |
